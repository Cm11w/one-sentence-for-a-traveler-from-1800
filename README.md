# One Sentence for a Traveler from 1800

Entry for the [make.fun bounty "One Sentence for a Traveler from 1800"](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) (sponsor: Po Pu, $2 prize pool).

## The task

Write a single sentence, at most 200 characters, that explains the modern
internet to a time traveler who has just stepped out of the year 1800.
The sentence must stand alone: no words coined after the traveler's time,
no list of features, just a picture they could actually hold in their head.

## The sentence

> It is a road of light joining every library and post office on earth, so any letter or book can reach any door in a breath.

123 characters, one sentence, one image. It is built only from things a
person from 1800 already knows — a road, a library, a post office, a
letter, a book, a door, a breath — and it is true of the internet as it
is now: light really does carry the words, through glass threads under
land and sea, between every store of knowledge and every house, arriving
in less time than a breath takes.

## How it works

`main.ts` writes the sentence to `/output/entry.txt`. The output is
fixed and deterministic: every run writes exactly the same bytes.

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 22.23.4).
